## ADR-001 : Utilisation de l'API python-garminconnect (vs SDK FIT officiel)

**Contexte :** La Forerunner 55 accepte-t-elle les fichiers .FIT
récupérés via l'API non-officielle garminconnect ?

**Décision :** Oui. Spike du 2026-08-06 validé : la FR55 reconnaît
les workouts placés dans /GARMIN/Workouts/{ID}.FIT. Le projet
utilisera garminconnect, pas le SDK FIT C.

**Alternatives écartées :** SDK FIT officiel (C, compilation croisée,
wrapper Python nécessaire). Écarté car complexité inutile.

**Conséquences :** Dépendance critique à garminconnect (reverse
engineering, risque de casse sur màj Garmin). Nécessite gestion
du rate limiting (429) et stockage sécurisé des credentials.
